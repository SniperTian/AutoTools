# AutoTools

**AutoTools** 是一款现代化的、轻量级的 Windows 自动化工具。它集成了鼠标连点、后台键盘队列及键鼠录制功能，旨在帮助用户从繁琐的重复操作中解脱出来。各功能分别位于三个页面，另有独立快捷键设置页。

本项目借助GPT6-Astra开发

## 启动

### 免安装程序

解压 `AutoTools-Windows-x64.zip`，打开 `AutoTools` 文件夹中的 `AutoTools.exe`。必须保留同目录下的 `_internal` 文件夹，不要只复制 EXE。不需要安装 Python。

### 使用已创建的 Conda 环境

双击源码目录的 `start.cmd`，它优先使用本机解释器：

`D:\Program\Anaconda\envs\game_assistant\python.exe`

也可以在 Anaconda Prompt 激活环境，进入本项目目录后运行：

```bat
conda activate game_assistant
python app.py
```

已在 Python 3.12.14 x64 / Windows 11 上测试。运行时使用 Tkinter、ctypes 和其他标准库，**不需要安装第三方 Python 包**。Windows 10 尚未进行实机验证。

## 快捷键

| 快捷键 | 操作 |
|---|---|
| F6 | 连点启动 / 停止 |
| F7 | 后台键盘队列启动 / 停止 |
| F8 | 录制开始 / 停止 |
| F9 | 录制回放开始 / 停止 |
| Ctrl+Alt+B | 绑定当前前台窗口 |
| Ctrl+Alt+F10 | 停止全部任务 |

可在设置页点击按键框后直接按键修改，再点击应用。当前页的注册冲突会明确显示；紧急停止快捷键不可用时不允许启动任务。不要同时启动多个实例，以免快捷键冲突。

支持直接捕获 F6、反引号、Home、End、PageUp、PageDown、Insert、Delete 和组合键；捕获时不启动工具。F12 是 Windows 调试保留键，不能作为全局快捷键。

只有当前工具页的启动快捷键生效；设置页不允许启动工具。窗口最小化或隐藏到托盘后，仍以最后选中的页面为准。正在运行的任务，其停止快捷键跨页有效；紧急停止始终有效。

一次只运行一个工具。切换页面不会中止任务。输入等待可中断，停止时会释放程序保持按下的键或鼠标键。

## 最小化到托盘

偏好设置中的“最小化到系统托盘”开关默认关闭，修改后自动保存；已有配置保留此前选择。勾选框使用放大的 ✓ 标记，说明位于右侧。

- **开启：** 点击右上角的最小化按钮，窗口隐藏到系统托盘，任务继续运行。
- **关闭：** 正常最小化到任务栏。
- **恢复窗口：** 双击 AutoTools 托盘图标，或右键选择“显示 AutoTools”。图标可能位于 Windows 托盘的折叠区域。
- **停止 / 退出：** 右键菜单提供“全部停止”和“退出”。退出时停止任务、释放输入并移除托盘图标。
- **关闭按钮：** 窗口右上角 × 仍然退出程序，不会仅隐藏窗口。

## 鼠标连点

- 左 / 右 / 中键，单击或双击。
- 间隔单位为秒，允许小数；一次完整动作结束后开始等待。
- 双击内部间隔为 0.06 秒，每次按下约 0.015 秒。是否被识别为双击取决于目标。
- 默认跟随真实鼠标位置，也可以选固定屏幕坐标。Y 坐标右侧的“3 秒后取点”按钮用于读取鼠标位置，点击后移动鼠标即可。
- 执行次数为 0 表示无限循环；双击作为一次执行计数。
- 默认 3 秒启动倒计时。

## 后台键盘队列

1. 在下拉列表按进程名、PID 和标题选择窗口。或者停留在键盘页，切换至目标窗口后按 Ctrl+Alt+B；绑定成功后弹窗显示进程、PID 和窗口标题。
2. 如需给某个输入控件发送消息，在“接收窗口”列表选择对应子窗口。快捷键绑定会优先选取当时有焦点的子窗口。
3. 添加按键步骤，输入按键名称或使用捕获按钮。
4. 设置按下时长和释放后的等待时间；轮数 0 表示无限循环。
5. 点击“开始后台执行”或按 F7。目标处于后台、最小化时仍发送消息，不激活或还原目标窗口。

支持字母、数字、F1–F24、方向键、SPACE、ENTER、ESC、TAB、HOME、END、PAGEUP、PAGEDOWN、NUM0–NUM9 等。组合键如 CTRL+Q、SHIFT+F1、CTRL+ALT+Q。组合键允许多个修饰键加一个主键，也可配置单独修饰键长按。

进程退出、窗口消失或进程身份发生变化时停止。重新启动目标后必须重新绑定。

### 后台兼容性的实际范围

本程序用 `PostMessageW` 发送 WM_KEYDOWN/WM_KEYUP 或 WM_SYSKEYDOWN/WM_SYSKEYUP，按正确顺序发送组合键，并填写扫描码、扩展键、释放状态等字段。

对于 Windows Edit / RichEdit 文本控件，Ctrl+A/C/X/V/Z、Ctrl+Insert、Shift+Insert/Delete 使用对应的编辑命令，Enter 使用字符消息，因此不依赖后台 Ctrl 状态。目标有唯一编辑子控件时自动选取；存在多个编辑区时，请手动选择接收窗口。

不能识别为 Edit / RichEdit 的目标不会把这些编辑组合键降级为字母输入，而会报错停止。文本控件中尚未适配的其他组合键同样会报告不支持。编辑命令立即执行一次，“按下时长”在此模式下是执行后的等待，不是物理长按。其他窗口仍使用按键消息，不能保证其识别修饰键。

**已验证后台与最小化的 Win32 测试窗口收到这些消息，且前台焦点不变。没有针对任何具体游戏验证。**

窗口消息不是物理键盘状态。依赖 Raw Input、DirectInput、异步键盘状态或自己的输入过滤逻辑的游戏，可能忽略消息；部分程序能收到字母键但无法识别组合键。最小化后暂停游戏逻辑的程序也可能不响应。本工具不能保证任意游戏后台运行，不包含驱动、进程注入或专用游戏适配。

发送成功仅代表消息已进入窗口队列，不能判定游戏执行了动作。发送进度使用“后台发送”描述。界面支持选择子窗口，用于适配采用子控件接收消息的软件。

## 录制与回放

- 录制键盘按下 / 释放、鼠标移动 / 按下 / 释放、垂直与水平滚轮、操作时间。
- 支持鼠标侧键 X1/X2 的录制与回放。
- 移动事件最多约 125 次/秒采样，点击和滚轮保留当时的位置。
- 本工具的全局控制快捷键、工具自己的界面操作和带注入标记的模拟输入不会录入。
- 若停止时有按键尚未释放，会在录制结尾补齐释放事件。
- 默认原速回放，可选 0.5 倍、1 倍、2 倍，指定轮数和轮间等待。
- 事件列表预览前 500 条，保存与回放使用全部事件。达到约 15 万事件或 24 小时上限时停止录制。

屏幕坐标模式按原屏幕位置回放，真实录制会校验显示器布局。窗口相对模式复用键盘页绑定的目标，允许窗口移动，但需要保持客户区大小不变；目标失焦、关闭或最小化时会停止录制 / 回放。

**只有键盘队列是后台工具，录制回放通过真实系统输入运行，需要把目标放在前台。** 屏幕模式无法判断应用内容是否变化，回放前应恢复所需界面。

请尽量使用 F8 停止录制，避免在结束时产生不必要的移动。回放前倒计时用于切换窗口。示例 `examples/recording.json` 只包含一次 A 键短按，加载后请在测试文本框中验证。

## 本地数据

- 配置和按键队列保存在程序旁边的 `data/settings.json`，包含托盘开关，但不自动恢复 PID 绑定。更新时可保留该文件夹继续使用已有设置。
- 队列支持单独导入 / 导出 JSON。
- 录制文件手动保存到选定位置；文件有版本号，加载时校验事件类型、时间、坐标、按键配对和大小。
- 录制不包含截图、音频或视频。所有数据保存在本地，不发送到网络。
- 建议把程序放在有写入权限的普通文件夹。

## 测试与构建

在源码目录运行：

```bat
python -m unittest discover -s tests -v
```

测试包含真实 Win32 消息接收窗口，验证后台、最小化、组合键顺序、长按停止释放、窗口身份失效、文件校验和录制过滤。点击与回放调度测试使用模拟发送器，避免自动点击用户其他应用。

可选重新打包：

```bat
python tools/generate_icon.py
python -m pip install pyinstaller==6.17.0
python build.py
python tools/package.py
python tools/verify_release.py
```

`build.py` 显式使用当前 Conda 环境的 Tcl/Tk DLL，避免 PATH 中其他环境的版本混入，并打包图标资源。EXE 输出在 `outputs/AutoTools-portable/AutoTools`。源码位于项目根目录，`tools/package.py` 生成 `AutoTools-source.zip` 和 `AutoTools-Windows-x64.zip`；`work` 存放构建中间文件。源码 ZIP 没有额外顶层目录，可直接解压到 `D:\Code\GameTool`。

## 技术文件

发布校验会保留并检查 `_internal/base_library.zip` 等完整运行库，将 ZIP 解压到新的测试目录，清除 Conda/Python 环境变量后运行 EXE 启动自检，验证内嵌 Python、Tcl/Tk 和图标加载。

- `app.py`：分页界面、配置、交互、事件分发。
- `assistant/win32.py`：类型完整的 Windows API、进程身份、输入发送。
- `assistant/engine.py`：单任务执行、可中断等待、循环与清理。
- `assistant/hooks.py`：全局快捷键、低级键鼠钩子、录制过滤。
- `assistant/model.py`：按键解析、数据校验、JSON 保存。
- `assistant/tray.py`：托盘图标、右键菜单和窗口恢复事件。
- `assets/autotools.svg`、`.png`、`.ico`：应用图标，ICO 包含多种尺寸。

计时不是硬实时；实际间隔受操作系统调度影响。普通权限程序不能向更高完整性级别的目标发送输入，出现权限错误时会报告，不会静默切换到前台。
